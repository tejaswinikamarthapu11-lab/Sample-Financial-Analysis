# Financial Sample Report Dashboard
## 📌 Project Overview

This project is an interactive Financial Sales & Profit Analysis Dashboard developed using Power BI to analyze business performance across different countries, customer segments, and discount categories.

The dashboard provides meaningful insights into:

Sales performance
Profit analysis
Discount trends
Segment-wise business growth
Country-wise sales distribution

It helps businesses make data-driven decisions by visualizing key financial metrics in a clear and interactive format.

🛠️ Tools & Technologies Used
Power BI – Dashboard creation & data visualization
Python (Pandas, NumPy) – Data cleaning & preprocessing
Excel / CSV Dataset – Data source
DAX – Calculated measures and KPIs
## 📊 Key Features
Interactive KPI Cards for:
Total Sales
Total Profit
Total Discounts
Dynamic Filters (Slicers):
Country Filter
Segment Filter
Profit Range Filter
Visualizations Included:
Profit by Segment
Sales by Country
Discounts by Segment
Geographic Sales Map
User-friendly dark themed dashboard design
## 📈 Key Insights
Government segment generated the highest profit.
United States contributed the highest sales among all countries.
Government and Small Business segments received the highest discounts.
Enterprise segment showed comparatively lower profit performance.
Geographic analysis helped identify region-wise sales distribution.
## 🎯 Business Impact

This dashboard can help organizations:

Monitor financial performance efficiently
Identify profitable business segments
Track discount effectiveness
Improve strategic decision-making
Analyze country-wise revenue contribution
